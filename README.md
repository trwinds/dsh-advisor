# dsh-advisor

A DeepSeek Harness plugin that lets an executor model consult an advisor model. 
The advisor receives the conversation history, then returns guidance.

In a conversation, use `/advisor` to toggle it on or off.

## Install

```sh
dsh plugin --profile web add github:trwinds/dsh-advisor
```
